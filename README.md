# techshift.ai

Website for [Techshift](https://techshift.ai). Static Astro site deployed to Cloudflare.

```bash
nvm use          # Node 24 LTS
npm install
npm run dev      # http://localhost:4321
npm run verify   # format check, lint, type check, build
npm run lighthouse
```

See [AGENTS.md](AGENTS.md) for structure, conventions, and deploy rules.
